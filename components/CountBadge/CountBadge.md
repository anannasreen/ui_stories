# CountBadge

A flexible badge component that displays a count value with optional icon and selection state.

## Props

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| count | `number` |  | The numeric value to display in the badge |
| icon | `React.ReactNode` |  | Optional icon element to display alongside the count |
| selected | `boolean` |  | Controls the selected state of the badge |
| onSelectionChange | `selected: boolean => void` |  | Callback fired when selection state changes |
