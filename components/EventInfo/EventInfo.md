# EventInfo

EventInfo component displays a piece of information with optional icon and severity.
Provides visual differentiation based on severity levels and layout options.

## Props

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| text | `React.ReactNode` |  | text for the event info |
| icon | `React.ReactNode` |  | icon for the event info |
| iconPosition | `enum` | `right` | position of the icon |
| severity | `enum` |  |  |
| variant | `enum` |  |  |
| muted | `boolean` |  |  |
