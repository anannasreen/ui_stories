The Cobalt component library is designed to make it as simple as possible to implement
user interfaces which look good, work well, and conform to our design language. By re-using
these components as much as possible, future investments in component quality will benefit
our entire frontend.

Note that only components in this library have been incorporated into Cobalt's design system
and confirmed to be reusable. If you need a re-usable component, check here. If it doesn't exist
yet, consider adding it to the list in the [Component Library Backlog](https://app.asana.com/0/1137791272238393/list).
