# LoadingSubtle

LoadingSubtle component provides a subtle loading animation.

```
<LoadingSubtle />
```

## Props

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| dotSize | `string` | `0.125em` | Size of the dots |
| duration | `string` | `0.6s` | Duration of the animation |
| height | `string` |  | Height of the loading subtle |
