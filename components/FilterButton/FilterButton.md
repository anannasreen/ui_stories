# FilterButton

FilterButton component displays a button with a label and optional icon.

```tsx
<FilterButton label="Filter" icon={<FilterIcon />} isActive={true} />
```

## Props

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| label | `string` |  | Label text for the button |
| isActive | `boolean` | `false` | Whether the filter is currently active |
| icon | `React.ReactNode` |  | Optional icon to display in the button |
| state | `enum` |  |  |
| isDisabled | `boolean` |  |  |
