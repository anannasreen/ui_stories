# FilterTabs

FilterTabs component for switching between different views or sections

## Props

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| value | `string` |  | The currently selected tab value |
| items | `FilterTabItem[]` |  | Array of tab items |
| onChange | `value: string => void` |  | Callback when a tab is selected |
| className | `string` |  | Optional className for styling |
| disabled | `boolean` |  | Whether all tabs are disabled |
